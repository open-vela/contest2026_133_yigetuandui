# Aura-Space 秦嘉一前端模块交接说明

版本：`v1.0.0`  
交接对象：项目整合、后端、IMU/硬件与数据架构成员  
运行环境：Windows/macOS/Linux + Node.js；浏览器建议 Edge/Chrome

## 二、整合人员如何查看

### 方法 A：Windows 一键启动

双击项目根目录的 `启动前端.bat`，然后打开：

```text
http://127.0.0.1:4173
```

### 方法 B：命令行启动

```bash
node server.mjs
```

项目零第三方运行依赖，不需要执行 `npm install`。

### 自检

```bash
npm run check
```

预期输出：

```text
Smoke tests passed: EventBus + FocusEngine
```

## 三、正式联调只改哪里

主要修改文件：`src/services/platform-adapter.js`

1. 后端实现 `docs/INTEGRATION.md` 中的 HTTP 接口；
2. 桌面左侧选择“真实 API”，填写后端地址；
3. IMU 手势事件映射到 `BeatFlicksRenderer.gesture(type)`；
4. Web 振动调用替换成真机振动服务；
5. 云端 AI 不可用时保留 `FocusEngine` 本地规则降级。

前端页面、CSS 动效、Canvas 渲染器和导航不需要重写。

## 四、推荐验收流程

1. 首页：确认五维数据、训练入口和趋势正常；
2. 音游：用 `A/W/D` 测试左甩、上抛、右甩；
3. N-Back：完成一次判断并看到正确/错误反馈；
4. 呼吸：启动计时，确认吸气/呼气动画；
5. AI 教练：询问“今天怎么练”，确认返回具体建议；
6. API 模式：启动后端后切换数据源，确认所有页面不改代码即可读取真实数据。

## 五、已知边界

- 当前交付是前端浏览器 Demo，不是可直接烧录到 SF32LB52 的固件或 RPK；
- 真机 UI Runtime、开发板 SDK、BLE/KV 和 AI Agent 由团队最终技术方案决定；
- 真机阶段仍需验证 60FPS、内存占用、触控热区、振动模式与功耗；
- 项目文档中姓名存在“秦家依/秦嘉一”两种写法，正式提交前需要全队统一。
